# OOP Web

เว็บ Java สำหรับทดลอง OOP ผ่านตัวอย่างค่าส่งพัสดุ ค่าจอดรถ ราคาตั๋ว และพลังโจมตีในเกม

ใช้ Java 21 ขึ้นไป เปิดเทอร์มินัลในโฟลเดอร์โปรเจกต์แล้วรันจากไฟล์ที่คอมไพล์ไว้

    java -cp build Main

ถ้าต้องการคอมไพล์จากซอร์สและเปิดเว็บด้วย PowerShell ให้รัน

    .\run.ps1

เปิดเว็บที่ [http://127.0.0.1:8765](http://127.0.0.1:8765/)
